# Lab 4

## 实现的功能

1. 移植上一个实验的功能
2. (easy-fs)：在 `EasyFileSystem` 上实现了 `dealloc_inode`，可以删除索引节点，用于删除文件/目录
3. (easy-fs)：在 `DiskInode` 上把 `clear_size` 改进为 `shrink_size`，用于删除磁盘上索引节点上的部分内容而不用清空整个节点
4. (easy-fs)：在 `Inode` 上实现了 `link` `unlink` `link_count`，分别用于创建硬链接、删除硬链接、硬链接计数。其中 `unlink` 通过上面实现的 `shrink_size` 和 swap remove 的方式进行，并在计数归 0 时通过上面实现的 `dealloc_inode` 回收索引节点和数据节点
5. (os)：在 `UserBuffer` 上实现了 `write` 方法，用于可能的跨页面写入数据
6. (os)：实现了 `sys_linkat` `sys_unlinkat` `sys_stat`
